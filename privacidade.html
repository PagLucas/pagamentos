Política de Privacidade — Alertas Lucas

Última atualização: 27 de outubro de 2026.

O aplicativo Alertas Lucas é uma ferramenta de uso pessoal de Lucas Cunha para enviar lembretes de vencimento de contas para o seu próprio WhatsApp. Não é oferecido ao público e não coleta dados de terceiros.

Dados tratados

O aplicativo trata apenas: o número de WhatsApp do próprio titular, o conteúdo das mensagens de alerta (descrição, valor e data de vencimento de contas) e as respostas enviadas pelo titular (por exemplo, a confirmação de pagamento).

Finalidade

Os dados são usados exclusivamente para enviar os alertas e registrar pagamentos no painel pessoal do titular. Não são vendidos, compartilhados ou usados para publicidade.

Armazenamento

Os dados ficam em banco de dados privado (Supabase), protegido por login. As mensagens trafegam pela plataforma oficial do WhatsApp (Meta).

Exclusão de dados

Para solicitar a exclusão de qualquer dado, envie e-mail para lucas@sparkadvisory.com.br. A exclusão é feita em até 7 dias.
